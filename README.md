# Wave Gliders Swim Club

Website for Wave Gliders Swim Club, a swimming academy in Nairobi, Kenya. It covers programmes and pricing, training venues, the club's story and founder, and contact details.

## Tech stack

React 19, Vite, Tailwind CSS 4, Framer Motion, lucide-react and react-icons.

## Getting started

```bash
npm install
npm run dev      # start the dev server
npm run build    # production build
npm run lint     # lint the code
```

## Project structure

```
src/
  App.jsx              page layout (sections in order)
  components/          NavBar, HomePage, Programmes, Services,
                       TrainingVenues, AboutUs, Ceo, Footer,
                       plus shared SectionHeader and Reveal
  assets/              images
```
